1. docker version: to find the docker version installed.

2. COPY <source_path> <destination_path>: helps to copy the files or directories from the host machine into the image.

3. RUN <command>: executes the specified command during the build process.

4. ENTRYPOINT ["executable", "arg1", "arg2", ...]: specifies the primary command to be run when a container is started.

5. docker build -t <image>:<tag> -f <Dockerfile_path> <context>: builds or creates a docker image from a Dockerfile located in the given path.

6. docker run --name <container_name> -d -e <evn_variable>=<value> <image>:<tag>: creates and starts a new container from the given image.

7. docker images: shows the list of docker images locally.

8. docker tag <source_image>:<source_tag> <username>/<destination_image>:<destination_tag>: creates a new alias for the existing image that includes the Docker Hub username and tag, which tells Docker where to push the image when you run docker push.

9. docker push <username>/<destination_image>:<destination_tag>: pushes the given docker image into the given docker hub repo.

10. docker pull <username>/<image_name>:<tag>: downloads the docker image from docker hub into the local system.

11. docker run -it -e MYSQL_ROOT_PASSWORD=admin -p 3306:3306 --hostname=mysql: run and download mysql image locally.

12. docker network create <network-name>: create docker network. 

13. docker network ls: to see list of docker networks.

14. docker network inspect <network-name or id>: inspect the given docker network.

* to run docker image with network: docker run -p 8080:8080 --network=223ccaf2cb8e gururaj7741/ecommerce-product-microservice:v1.0

* to run mysql docker image with network: docker run -it -e MYSQL_ROOT_PASSWORD=admin -p 3306:3306 --hostname=mysql-host-product-microservice --network=223ccaf2cb8e mysql

* to run docker image with environment variable: docker run -p 8080:8080 --network=223ccaf2cb8e -e MYSQL_HOSTNAME=mysql-host-product-microservice -e MYSQL_PASSWORD=admin gururaj7741/ecommerce-product-microservice:v1.0

* to run mysql docker image with default mysql db file with sql commands: docker run -it -e MYSQL_ROOT_PASSWORD=admin -p 3306:3306 --hostname=mysql-host-product-microservice --network=223ccaf2cb8e -v ./mysql-init:/docker-entrypoint-initdb.d mysql --lower_case_table_names=1

15. docker-compose config: not to run the docker file but to check the syntax and errors in the file.

16. docker-compose up: creates, starts all services (containers) and networks defined in .yml file.

17. docker-compose down: stops and removes all containers and networks defined in yaml file.

18. docker-compose start: Starts the existing container and networks in .yml file won't recreate it.

19. docker-compose stop: stops the containers and networks but doesn't remove them.

20. docker-compose restart -f filenameWithPath.yaml: Stops and restarts all the container, won't remove them.

21: docker-compose pause: Pauses the containers.

22: docker-compose unpause: resumes the containers.

* to run these commands in detached mode in terminal just use -d

23: docker compose ps: show created container that are running.

24: docker exec -it my-sql-container-name MySQL -u root -p databasename: run MySQL docker container in interactive mode with username and password.

25: docker inspect <container>: view detailed information about a docker container.

26: docker logs <container>: View the logs of a running or stopped docker container.

27: docker rmi <image>:<tag>: to remove docker image.
