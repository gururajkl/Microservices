1. As a first step login to azure using the below command:
>> az login
So this command will ask mail and password enter the same and do login
After login select the required subscription and start coding.

2. In azure to create any services those services should be under a resource group.
So first I need to create a resource group in azure using the below command:
>> az group create --name ecommerce-resource-group --location "South India"

3. Once the group is created the next job is to create azure container registry (acr) using below command:
>> az acr create --resource-group ecommerce-resource-group --name gjecommerceregistry --sku Basic

4. To work with AKS (Azure Kubernetes Service) we need to register some providers, register the below providers using the below commands.
>> az provider register --namespace Microsoft.Insights --wait [Enables monitoring and diagnostics for Azure resources]
>> az provider register --namespace Microsoft.OperationalInsights --wait [Supports Log Analytics for operational data monitoring]
>> az provider register --namespace Microsoft.ContainerService --wait [Manages Azure Kubernetes Service (AKS) and container workloads]
>> az provider register --namespace Microsoft.Network --wait [Provides network-related services like VNETs, Load Balancers, and VPNs]
>> az provider register --namespace Microsoft.Compute --wait [Manages virtual machines, scale sets, and related compute resources]
>> az provider register --namespace Microsoft.OperationsManagement --wait [Handles operations management solutions, like Azure Automation]
>> az provider register --namespace Microsoft.Authorization --wait [Manages access control (RBAC) and policy settings for resources]
>> az provider register --namespace Microsoft.Storage --wait [Manages Azure Storage services like blobs, files, and queues]

5. After registering providers, next job is to create AKS clusters using the below command:
>> az aks create --resource-group ecommerce-resource-group --name ecommerce-aks-cluster --node-count 1 --node-vm-size Standard_B2s --enable-addons monitoring --generate-ssh-keys

6. As a next step I need to get aks credentials and save locally using below command:
>> az aks get-credentials --resource-group ecommerce-resource-group --name ecommerce-aks-cluster

7. To confirm if the credentials are saved run the below command:
>> kubectl cluster-info

8. Now go to demo weather app created earlier and create yaml file and add settings and configurations

9. Before running the yaml file make sure the web app container and image is pushed into the gjecommerceregistry using below command:
Before pushing the image first I need to login into the container registry using below command:
>> az acr login --name gjecommerceregistry
Once login done I need build the docker file using the below command:
>> docker build -t demowebapp:latest -f ./DemoWebApplication/Dockerfile .
Once docker image build is done, i need to tag the local image to azure container registry path using the below command:
>> docker tag demowebapp:latest gjecommerceregistry.azurecr.io/demowebapp:latest
After tagging done push the image into the azure container registry using below command:
>> docker push gjecommerceregistry.azurecr.io/demowebapp:latest

10. Once image is pushed i need to attach the container registry to the cluster using below command:
>> az aks update --resource-group ecommerce-resource-group --name ecommerce-aks-cluster --attach-acr gjecommerceregistry
